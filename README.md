## 🛠️ Cómo trabajo

- **Multi-tenant de verdad** — un solo despliegue sirve a todos los clientes, con los datos aislados en la base de datos (RLS), no en el frontend.
- **Restricciones en la base de datos, no en el cliente** — por ejemplo, índices únicos parciales para que la doble reserva sea *imposible*, no solo improbable.
- **Server-side por defecto** — App Router, revalidación y cero estado innecesario en el navegador.
- **Seguridad desde el día uno** — CSP y HSTS, captcha invisible, rate limiting y secretos siempre en variables de entorno.
